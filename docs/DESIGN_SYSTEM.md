# SmartShop AI Design System

Branch: smartshop-ai. This iteration is PREVIEW ONLY.

- Brand: SmartShop AI / 一个人，也能运营一家智能电商公司.
- Colors: indigo #4f46e5, hover #4338ca, violet accents, navy #0b1025, background #f6f7fb.
- Global styles: consistent buttons, typography, shadows, cards, focus states, reduced motion support.
- Landing: premium hero, labeled product workflow preview, feature cards, trustworthy empty catalog, integrated calls to action.
- Navigation: responsive site header, mobile overlay, footer and dashboard sidebar.
- Admin: real payment-aware KPI overview, real six-month history, recent orders and low stock, quick actions, AI tool cards.
- Product selection: public links lead to authenticated admin page, live catalog vs explicitly labeled fictional demonstration comparison.
- AI key remains deferred. No invented revenue is represented as actual.
- Verify preview build and browser flows before any production release.
